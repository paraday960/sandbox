# 🪞 سورس سندباکس — خودِ برنامه!

این پوشه سورس کامل همین اپیه که توش هستی. می‌تونی:
- از تب «📂 فایل‌ها» هر فایلی رو ویرایش کنی (مثلاً assets/index.html = کل رابط کاربری!)
- از تب «🤖 چت» از بات بخواه فیچر اضافه کنه یا باگ بگیره
- از تب «🛠 ساخت» دکمه‌ی «🔨 ساخت نسخه‌ی جدید خودم» رو بزنی
- بعدش «📦 نصب آپدیت» — برنامه خودش رو آپدیت می‌کنه!

نسخه هر بار خودکار یکی زیاد می‌شه.
