# 📱 phonebox — گوشیِ تو، سرورِ تو

گوشی اندرویدت رو با یه **تونل رایگان Cloudflare** (بدون ثبت‌نام!) به یه API شخصی تبدیل می‌کنه تا ایجنت بتونه از راه دور بهش وصل بشه و از رم، حافظه و پردازنده‌ی گوشی استفاده کنه.

---

## 🚀 راه‌اندازی (۳ دقیقه)

### ۱) نصب Termux
از **F-Droid** نصب کن (نسخه‌ی گوگل‌پلی قدیمیه و کار نمی‌کنه):
👉 `https://f-droid.org/packages/com.termux/`

### ۲) اجرای اسکریپت
Termux رو باز کن و **کل محتوای فایل `termux-setup.sh`** رو پیست کن و Enter بزن.

یا اگر لینک دانلود بهت داده شد، فقط این یک خط:

```bash
curl -sL <لینک> | bash
```

اسکریپت خودش:
- پایتون و `cloudflared` رو نصب می‌کنه
- یه توکن مخفی ۲۸ کاراکتری می‌سازه
- سرور `phonebox` رو روی گوشی اجرا می‌کنه
- تونل رایگان `trycloudflare.com` رو باز می‌کنه

### ۳) فرستادن اطلاعات به ایجنت
آخر کار دو خط نشانت داده می‌شه — هر دو رو عیناً برام بفرست:

```
✅ آدرس API : https://xxx-yyy-zzz.trycloudflare.com
🔑 توکن     : abc...XYZ
```

ایجنت از اون لحظه می‌تونه این کارها رو روی گوشی تو انجام بده:

| دستور | کار |
|---|---|
| `ping` / `info` | وضعیت گوشی: رم، حافظه، مدل |
| `exec "..."` | اجرای دستور شل روی گوشی |
| `py "..."` | اجرای کد پایتون روی گوشی |
| `put/get/rm` | گذاشتن و برداشتن فایل در باکس اسناد گوشی |
| `storage` | فضای خالی حافظه‌ی اصلی گوشی |

---

## 🔒 امنیت

- سرور فقط روی `127.0.0.1` گوش می‌ده و **فقط** از داخل تونل قابل دسترسیه.
- بدون **توکن**، هیچ کاری قابل انجام نیست (هر درخواست غلط → `403`).
- آدرس تونل تصادفیه ولی «عمومی» محسوب می‌شه — پس **آدرس + توکن رو به هیچ‌کس دیگه‌ای نده.**
- هر وقت خواستی قطعش کنی، در Termux بزن:
  ```bash
  pkill cloudflared ; pkill -f server.py
  ```
- ترجیحاً گوشی رو شارژ بذار و Termux رو در تنظیمات باتری «بدون محدودیت» (Unrestricted) کن تا اندروید نکشتش.

## 🛠 عیب‌یابی

- **«cloudflared نصب نشد»** → دستی: `pkg install cloudflared`
- **تونل ساخته نشد** → `cat ~/sandb0x/tunnel.log` و متن خطا رو بفرست
- **پس از قطع وصل شدن دوباره** → در Termux: `cd ~/sandb0x && bash start.sh` (اگر فایل نبود، همون اسکریپت اصلی رو دوباره پیست کن)
- **دسترسی به حافظه‌ی اصلی گوشی** → یک‌بار در Termux بزن: `termux-setup-storage`

## 📂 فایل‌ها

- `termux-setup.sh` — اسکریپت خودکفایی که در Termux پیست می‌شه
- `server.py` — سورس مستقل سرور (همون که داخل اسکریپت جاسازی شده)
- `client.sh` — کلاینتی که ایجنت از این‌طرف استفاده می‌کنه
