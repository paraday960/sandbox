# 📦 سندباکس (SandBox)

**گوشیِ تو، سرورِ تو** — یه اپ اندرویدی که گوشیت رو به یه محیط برنامه‌نویسی کامل تبدیل می‌کنه: لینوکس، پایتون، بات هوش مصنوعی، کامپایلر، پیش‌نمایش زنده و تونل امن. بدون روت، بدون سرور، رایگان.

> ساخته‌شده به‌همراه یک ایجنت هوش‌مصنوعی 🤖

## ✨ ۱۰ تب، یک ورک‌اسپیس

| تب | توضیح |
|---|---|
| 📊 داشبورد | وضعیت رم/حافظه + آزمون رم + بازسازی محیط |
| 🤖 چت | **بات هوش مصنوعی عامل** — به ترمینال و فایل‌های گوشی دسترسی دارد (Gemini یا OpenAI-سازگار با کلید خودت) |
| 🐧 ترمینال | بش واقعی لینوکس + ۱۰۰ ابزار |
| 🐍 پایتون | مفسر پایتون ۳ + pip روی پردازنده‌ی گوشی |
| 📂 فایل‌ها | **ورک‌اسپیس کامل**: مرور، ساخت، ویرایش، تغییر نام، حذف، زیپ، اشتراک، ایمپورت |
| 🖥 نمایش | **پیش‌نمایش زنده**: وب‌سرور داخلی + مرورگر + کنسول + رفرش خودکار |
| 📦 بسته‌ها | **مدیر بسته** (mini-apt): نصب هر بسته‌ای با وابستگی‌ها — nodejs، git، ffmpeg، … |
| 🛠 ساخت | **کامپایل روی گوشی**: APK اندرویدی (javac→d8→aapt2→امضا)، C/C++ با clang — بدون GitHub Actions! |
| 🗂️ اسناد | باکس اسناد + خروجی/ورودی |
| 🌉 اتصال | تونل رایگان Cloudflare + API امن → کنترل کامل از راه دور |

## 🔌 API راه دور (تونل)

```
GET /ping /info /storage
GET|POST|DELETE /docs…        (اسناد)
POST /exec {"cmd":"…"}        (شل)
POST /py                      (پایتون)
POST /pkg/install {"name":…}  GET /pkg/job /pkg/search?q=… 
GET  /preview/…               (پیش‌نمایش سایت ساخته‌شده روی گوشی)
GET|POST /ws…                 (ورک‌اسپیس)
```
همه با هدر `Authorization: Bearer TOKEN` — بدون توکن هیچ.

## 🛡 مدل امنیتی ۵ لایه

1. سندباکس کرنل اندروید — دسترسی به سیستم/اپ‌های دیگر فیزیکیاً ناممکن
2. صفر مجوز حافظه
3. `usr` فقط‌خواندن (بات/ورک‌اسپیس/API)
4. نگهبان دستورها — مسدودسازی `rm -rf /usr`، `apt remove` و… در همه‌ی مسیرها
5. ♻️ بازسازی محیط لینوکس بدون از دست رفتن داده‌ها

## 📲 نصب

آخرین `SandBox.apk` را از [Releases](../../releases) بگیرید و نصب کنید (اندروید ۷+، arm64). سپس: داشبورد → 🐧 نصب لینوکس (~۳۰MB) → 🐍 پایتون + تونل (~۱۷MB). از v4.1 به بعد، بیلدکیت (~۱۰۰MB) هم برای تب ساخت قابل نصب است. APK از v7 به بعد ~۲۴MB است (android.jar جاسازی‌شده برای کامپایل آفلاین).

## 🏗 ساخت از سورس

```bash
bash app/build.sh   # فقط JDK11 + build-tools 35 + این ریپو
```

## 🧰 اعتبارها

- بوت‌استرپ لینوکس: [Termux](https://termux.dev) — GPLv3 (استفاده‌ی شخصی آزاد)
- تونل: [cloudflared](https://github.com/cloudflare/cloudflared) / trycloudflare
- بسته‌ها: مخزن رسمی Termux + میرورهای اروپایی (grimler.se، fau.de) + پشتیبان F-Droid
