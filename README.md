# 📦 سندباکس (SandBox)

**گوشیِ تو، سرورِ تو** — یه اپ اندرویدی که گوشیت رو به یه محیط برنامه‌نویسی کامل تبدیل می‌کنه: لینوکس، پایتون، مدیر بسته و تونل امن برای دسترسی از راه دور. بدون روت، بدون سرور ابری، کاملاً رایگان.

> ساخته‌شده به‌همراه یک ایجنت هوش‌مصنوعی 🤖 — از ایده تا انتشار، داخل سندباکس ابری.

---

## ✨ امکانات

| تب | توضیح |
|---|---|
| 📊 داشبورد | وضعیت رم/حافظه/باتری + آزمون تخصیص رم |
| 🐧 ترمینال | **بش واقعی لینوکس** با ۱۰۰+ ابزار (bash, grep, sed, curl, tar, …) |
| 🐍 پایتون | مفسر پایتون ۳ روی پردازنده‌ی گوشی + `pip` |
| 📦 بسته‌ها | **مدیر بسته‌ی کامل** — نصب هر بسته‌ای از مخزن Termux با حل خودکار وابستگی‌ها (nodejs، git، ffmpeg، …) |
| 🗂️ اسناد | باکس اسناد با حافظه‌ی خود گوشی + خروجی/ورودی فایل |
| 🌉 اتصال | **تونل رایگان Cloudflare** + API امن → کنترل کامل گوشی از راه دور |

## 🔌 API راه دور

بعد از روشن‌کردن تونل، این مسیرها با هدر `Authorization: Bearer TOKEN` در دسترسه:

```
GET  /ping  GET /info  GET /storage
GET/POST/DELETE /docs…        (باکس اسناد)
POST /exec    {"cmd": "..."}  (اجرای شل)
POST /py      (بدنه = کد پایتون)
POST /pkg/install {"name":"nodejs"}  +  GET /pkg/job  +  GET /pkg/search?q=…
```

## 📲 نصب

1. آخرین `SandBox.apk` را از [Releases](../../releases) دانلود کنید
2. روی گوشی نصب کنید (اجازه‌ی «منبع ناشناس» لازم است — اپ سایدلود شخصی است)
3. داشبورد → 🐧 نصب لینوکس (~۳۰MB) → 🐍 پایتون + تونل (~۱۷MB)
4. تمام! همه‌چیز آفلاین هم کار می‌کند

**سازگاری:** اندروید ۷ به بالا (API 24+)، فقط پردازنده‌ی arm64 (اغلب گوشی‌های امروزی)

## 🛡 نکات امنیتی و شبکه

- سرور داخلی فقط روی `127.0.0.1` گوش می‌دهد و بدون توکن هیچ کاری ممکن نیست
- IP واقعی گوشی هرگز در تونل ظاهر نمی‌شود (Cloudflare پوشاننده است)
- تونل با پروتکل http2 روی پورت ۴۴۳ + اتصال مجدد خودکار (۱۲ بار)
- **میرورهای پشتیبان مخزن بسته‌ها:** سوئد (grimler.se) و آلمان (ftp.fau.de) — برای شبکه‌های تحریم‌شده
- **پشتیبان بوت‌استرپ:** اگر گیت‌هاب در دسترس نبود، خودکار از F-Droid (اروپا) نصب می‌شود
- کارت پروکسی اختیاری برای عبور ترافیک ترمینال از VPN/پروکسی شخصی

## 🏗 ساخت از سورس

بدون Gradle — فقط با ابزارهای SDK:

```bash
# پیش‌نیاز: JDK 11 و Android build-tools 35 + platform-34
bash app/build.sh    # → SandBox.apk (امضاشده با کلید debug)
```

ساختار:
```
app/
├── AndroidManifest.xml
├── src/com/sandbox/box/MainActivity.java   # کل اپ (جاوا، بدون وابستگی)
├── assets/index.html                        # رابط کاربری فارسی (تک‌فایل)
├── assets/pkglist.json                      # بسته‌های نصب اولیه (python, cloudflared, …)
├── res/mipmap-*/                            # آیکون
└── build.sh
phonebox/         # نسخه‌ی Termux (مرحله‌ی اول پروژه) — سرور + کلاینت
```

> **نکته:** `app/keys/` (کلید امضا) عمداً در گیت نیست — در دستگاه خودتان نگهش دارید تا آپدیت‌های بعدی روی نصبِ فعلی بنشیند.

## 🧰 اعتبارها

- محیط لینوکس: بوت‌استرپ رسمی [Termux](https://termux.dev) — مجوز **GPLv3** (استفاده‌ی شخصی آزاد است)
- تونل: [cloudflared](https://github.com/cloudflare/cloudflared) + trycloudflare
- بسته‌ها: مخزن رسمی [Termux Packages](https://packages.termux.dev)
